## 1. 📖 About The Project

### Overview & Core Purpose
Modern digital platforms are engineered to capture human attention through addictive notification loops and doomscrolling algorithms. **FocusFlow** flips the attention economy on its head: instead of losing focus to free-to-play apps, users **get paid in digital currency to focus, learn, and meditate**.

By transforming deep work, daily micro-learning, and mindfulness into measurable incentives, FocusFlow provides users with immediate positive reinforcement (coins, daily streaks, milestone celebrations) that can be redeemed for high-utility subscriptions (ChatGPT Plus, Coursera Plus, Spotify, Notion) and gift cards (Amazon, Flipkart, Starbucks, Swiggy).

## 4. 🏗️ System Architecture & Engineering

```
┌────────────────────────────────────────────────────────────────────────┐
│                        FOCUSFLOW ARCHITECTURE                          │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   CLIENT TIER (HTML5 / Vanilla JS / Lucide / Design Tokens)           │
│   ├── Landing Page (index.html, js/main.js)                            │
│   ├── User Dashboard (dashboard.html, js/dashboard.js)                 │
│   ├── Marketplace (redeem.html, js/redeem.js)                          │
│   └── Resilient Client Storage Engine (js/config.js, js/mock-data.js)  │
│                                                                        │
│                           ▼ (Automatic Fallback Bridge)                │
│                                                                        │
│   SERVER TIER (Node.js 20 / Express 4.18)                              │
│   ├── Auth & Session Management (express-session, bcryptjs)           │
│   ├── REST API Routing (/api/auth, /api/coins, /api/courses, etc.)     │
│   └── Database Layer (sql.js SQLite WASM / users.json)                 │
│                                                                        │
│                           ▼                                            │
│                                                                        │
│   DEPLOYMENT TARGETS                                                   │
│   ├── Google Firebase Hosting (Global CDN, Clean URLs, No-Cache)       │
│   └── Render.com Blueprint (render.yaml for one-click backend deploy)   │
└────────────────────────────────────────────────────────────────────────┘
```

### Dual-Engine Resilient Design
1. **Serverless Edge Fallback (`js/config.js`)**:
   - Ensures the platform runs **100% free and functional on Firebase Hosting (Spark Plan)** without requiring billing/credit cards for Cloud Functions.
   - Transparently handles all authentication, coin transactions, course completions, and redemptions directly in `localStorage` if no remote backend is present.
2. **Production Node.js Backend (`server/server.js`)**:
   - SQLite relational database powered by `sql.js` (pure WebAssembly, zero native C++ compilation bindings required).
   - Serverless filesystem protection: automatically routes persistent database writes to `os.tmpdir()` in read-only cloud container environments.
   - Secure cookie isolation with `__session` naming strictly compatible with Firebase Hosting's CDN reverse-proxy cache.

## 6. 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org) (v18, v20, or higher)
- [Git](https://git-scm.com)

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Action-kamen257/focusflow-platform.git
   cd focusflow-platform
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment:**
   ```bash
   cp .env.example .env
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```

5. **Open in browser:**
   ```
   http://localhost:3000
   ```
   - **Dashboard**: `http://localhost:3000/dashboard.html`
   - **Marketplace**: `http://localhost:3000/redeem.html`

## 7. 🔒 Security & Secrets Protection

- **Zero Secret Leaks**: All private keys, `.env` files, production credentials, and SQLite database binaries (`*.db`) are strictly ignored via comprehensive [`.gitignore`](.gitignore) rules.
- **Sample Config Only**: Only safe, sanitised `.env.example` templates are tracked.
- **Session Protection**: Passwords are securely hashed with `bcryptjs` (salt rounds: 10), and session cookies use `HttpOnly`, `SameSite: Lax`, and `Secure` attributes in production.
